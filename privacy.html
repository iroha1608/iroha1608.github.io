プライバシーポリシー / Privacy Policy

制定日 / Effective date: 2026-10-19

対象 / Scope

このポリシーは、開発者本人だけが使うツール cal2obsidian と news-digest に適用されます。ほかの人のデータは扱いません。
This policy applies to cal2obsidian and news-digest, tools used only by the developer. They do not handle anyone else's data.

アクセスするデータ / Data accessed

  • cal2obsidian: Google カレンダーの予定（読み取りと、本人が指示した予定の作成）
    Google Calendar events (read, and create events the user asks for)
  • news-digest: Gmail のうち、設定した差出人（ニュースレターの配信元）から届いたメールだけ（読み取り専用。Gmail 側は変更しない）
    Only Gmail messages from configured newsletter senders (read-only; nothing in Gmail is modified)

利用目的 / How the data is used

本人の Obsidian のノートを作るためだけに使います。広告・販売・AI モデルの学習には使いません。
The data is used only to create the user's own Obsidian notes. It is never used for advertising, sold, or used to train AI models.

保存場所 / Storage

データは本人の PC（設定・状態のファイル）と本人の Obsidian の Vault にだけ保存します。開発者のサーバーはありません。
Data is stored only on the user's own computer and in the user's own Obsidian vault. There is no developer-operated server.

外部への送信 / Data sent to third parties

  • news-digest は、翻訳・要約・語彙の抽出のため、ニュースレターの本文を Anthropic の Claude に送ります。
    news-digest sends newsletter text to Anthropic's Claude to translate and summarize it and to extract vocabulary.
  • 両ツールは、通知のため予定や記事の見出しを本人の Discord のチャンネルに送ります。
    Both tools send notifications (event titles or article headlines) to the user's own Discord channel.

Google API から受け取った情報の利用は、Limited Use の要件を含む Google API Services User Data Policy に従います。
The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

アクセスの取り消し・削除 / Revoking access and deletion

Google アカウントの「サードパーティ製のアプリとサービス」からいつでもアクセスを取り消せます。保存したデータは、PC のファイルと Vault のノートを削除すれば消えます。
Access can be revoked at any time from the Google Account's "Third-party apps & services" page. Stored data is removed by deleting the local files and notes.
